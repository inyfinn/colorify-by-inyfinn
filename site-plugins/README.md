# Wtyczki stron klientów

Wtyczki dla pojedynczych stron, w stylu Colorify. Colorify ich nie ładuje: leżą tutaj, żeby wszystko było w jednym repozytorium.
Każde wydanie Colorify dołącza każdą z nich jako osobny plik ZIP (np. `kw-uslugi.zip`), gotowy do wgrania w Wtyczki, Dodaj nową.

| Folder | Strona | Co robi |
|---|---|---|
| `kw-uslugi/` | Kancelaria Wieczorek (kancelaria-wieczorek.com.pl) | cennik usług i edytor usług w panelu |

Wersja wtyczki jest w nagłówku jej głównego pliku (`kw-uslugi/kw-uslugi.php`), niezależnie od wersji Colorify.
Dawne osobne repozytorium `inyfinn/kw-uslugi` jest zarchiwizowane; zmiany idą tylko przez ten folder.
